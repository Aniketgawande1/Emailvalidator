

## 📧 Email Validator CLI Tool

A simple Python command-line tool to validate email addresses using regular expressions.

---

### 🛠️ Features

* ✅ Validates email format using regex
* 🧑‍💻 CLI support for one-time validation
* 🗣️ Interactive mode to validate multiple emails in a session

---

### 📦 Requirements

* Python 3.x

---

### 🚀 Installation

Clone the repo or download the file:

```bash
git clone https://github.com/your-username/email-validator-cli.git
cd email-validator-cli
```

Or simply download `email.py`.

---

### 🔧 Usage

#### ✅ Validate a single email:

```bash
python email.py someone@example.com
```

#### 🗣️ Run in interactive mode:

```bash
python email.py --interactive
```

Type `exit` to quit the interactive session.

---

### 🧪 Example

```bash
$ python email.py test@gmail.com
✅ test@gmail.com is valid

$ python email.py --interactive
Enter an email to validate (or type 'exit' to quit): hello@domain
❌ Invalid
Enter an email to validate (or type 'exit' to quit): exit
Goodbye!
```
